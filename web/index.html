What the checks can tell you

Two resource URLs per dataset are checked each week: downloadable formats first, then English resources. HTTP 404 or 410 is a failed lookup at that time. HTTP 401, 403 and 429 means blocked or rate limited. Network errors and other responses are inconclusive. A 200 response can still be an error page; this monitor does not validate file contents.

Dates and expected updates

Portal metadata modification and the publisher's modification date are shown separately. The declared frequency is preserved as published, but does not create a firm deadline. Your age threshold flags old portal metadata for review; it cannot prove that the underlying data is late.

History, scope and privacy

The watchlist is eight deliberately selected records, not the entire federal catalogue. Raw metadata and dated snapshots are retained in this public repository. The first capture is a baseline; changes appear only after another successful capture. Failed metadata collection leaves the previous data online. Searching, filtering and exporting stay in this tab. Opening source links contacts those publishers. The shared CoolCode counter measures aggregate opens, without filter values.

Sources and reuse

Metadata comes from Canada's public CKAN API, with resource-specific licences shown in the original catalogue. Follow the Open Government Licence – Canada where applicable. This independent project is not a Government of Canada service.
